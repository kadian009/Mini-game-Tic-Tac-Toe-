# Mini-game-Tic-Tac-Toe-

📌 Overview

This project is a console-based Tic Tac Toe game developed in C++. It is a two-player game where players take turns marking spaces in a 3×3 grid.

The game demonstrates fundamental programming concepts like loops, arrays, and conditional logic.

🎮 Features

👥 Two-player gameplay
🧩 3x3 game board
🔄 Turn-based moves (Player X and Player O)
🏆 Win detection system
🤝 Draw detection
🔁 Option to replay the game
📟 Simple console-based interface

🛠️ Technologies Used

Language: C++

Concepts:

Arrays ,
Loops ,
Functions ,
Conditional Statements

How It Works

The game board is displayed using a 2D array.
Players take turns entering positions (1–9).
The system checks after each move:  
If a player has won or 
If the game is a draw. 

The game ends when a win/draw condition is met
